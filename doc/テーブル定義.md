# テーブル定義書
---

## 1. 参照データ

### `currency`
| 列名 | 型 | NOT NULL | 説明 |
|---|---|---|---|
| ccy | TEXT (PK) | Y | 通貨コード（3文字） |

### `daycount`
| 列名 | 型 | NOT NULL | 説明 |
|---|---|---|---|
| code | TEXT (PK) | Y | 例: ACT/365F |
| description | TEXT | Y | 説明 |

### `bizday_convention`
| 列名 | 型 | NOT NULL | 説明 |
|---|---|---|---|
| code | TEXT (PK) | Y | MF, F, P など |
| description | TEXT | Y | 説明 |

### `calendar`
| 列名 | 型 | NOT NULL | 説明 |
|---|---|---|---|
| cal_id | TEXT | Y | 暦ID（JPTO, USNY など） |
| holiday | TEXT | Y | 休日日付（YYYY-MM-DD） |

### `ref_rate_index`
| 列名 | 型 | NOT NULL | 説明 |
|---|---|---|---|
| index_id | TEXT (PK) | Y | 例: USD-SOFR |
| ccy | TEXT → `currency.ccy` | Y | 通貨 |
| tenor | TEXT | Y | ON, 1M, 3M など |
| daycount | TEXT → `daycount.code` | Y | 日数計算 |

---

## 2. マーケット・スナップショット

### `snapshot`
| 列名 | 型 | NOT NULL | 説明 |
|---|---|---|---|
| snapshot_id | TEXT (PK) | Y | 識別子 |
| as_of | TEXT | Y | 評価日 |
| src_tag | TEXT |  | 取得元タグ |
| data_hash | TEXT | Y | 入力ハッシュ |
| created_at | TEXT | Y | 作成UTC |

### `fx_spot`
| 列名 | 型 | NOT NULL | 説明 |
|---|---|---|---|
| snapshot_id | TEXT → `snapshot.snapshot_id` | Y | 参照 |
| pair | TEXT | Y | 例: USDJPY |
| spot | REAL | Y | スポット |

### `curve_def`
| 列名 | 型 | NOT NULL | 説明 |
|---|---|---|---|
| curve_id | TEXT (PK) | Y | 曲線ID |
| ccy | TEXT → `currency.ccy` | Y | 通貨 |
| curve_type | TEXT | Y | OIS, FORECAST など |
| index_id | TEXT |  | 予測曲線の基準インデックス |
| daycount | TEXT → `daycount.code` | Y | 日数計算 |
| compounding | TEXT | Y | CONT, SIMPLE など |
| cal_id | TEXT |  | 暦ID |

### `curve_point`
| 列名 | 型 | NOT NULL | 説明 |
|---|---|---|---|
| snapshot_id | TEXT → `snapshot.snapshot_id` | Y | 参照 |
| curve_id | TEXT → `curve_def.curve_id` | Y | 参照 |
| tenor | TEXT | Y | テナー |
| pillar_date | TEXT |  | 実日付 |
| zero_rate | REAL |  | 連続複利 |
| discount_factor | REAL |  | 割引因子 |

### `vol_fx`
| 列名 | 型 | NOT NULL | 説明 |
|---|---|---|---|
| snapshot_id | TEXT → `snapshot.snapshot_id` | Y | 参照 |
| pair | TEXT | Y | 通貨ペア |
| expiry | TEXT | Y | 満期 |
| strike_tag | TEXT | Y | ATM, K=150 等 |
| quote_type | TEXT | Y | LN_VOL, N_VOL |
| sigma | REAL | Y | ボラ |

### `vol_capfloor` / `vol_swaption`
同様に `ccy, expiry, tenor, quote_type, sigma` を保持。

### `model_param`
| 列名 | 型 | NOT NULL | 説明 |
|---|---|---|---|
| snapshot_id | TEXT → `snapshot.snapshot_id` | Y | 参照 |
| model_tag | TEXT | Y | BLACK 等 |
| scope | TEXT | Y | CCY, PAIR, INDEX, GLOBAL |
| param_key | TEXT | Y | スコープキー |
| param_name | TEXT | Y | 例: shift |
| param_val | REAL | Y | 値 |
